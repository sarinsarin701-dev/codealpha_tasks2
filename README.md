# Fitness Tracking App

## Project Overview

The Fitness Tracking App is a simple and user-friendly mobile application developed to help users track their daily fitness activities.

The app allows users to manually record activities such as exercise type, workout duration, calories burned, and steps. It also provides a dashboard to view daily progress and activity summaries.

## Features

* Track daily steps
* Record workout duration
* Record calories burned
* Add different exercise activities
* View today's fitness summary
* Visual progress bars
* Weekly activity graph
* View recent activities
* Delete recorded activities
* Simple and clean user interface

## Technologies Used

* React Native
* Expo Snack
* JavaScript
* React Hooks
* React Native UI Components

## How It Works

1. Open the Fitness Tracking App.
2. The dashboard displays today's activity summary.
3. Enter the exercise type.
4. Enter workout duration.
5. Enter calories burned.
6. Enter the number of steps.
7. Click **Add Activity**.
8. The activity is added to the recent activities list.
9. The dashboard automatically updates the total steps, calories, and workout time.
10. Users can delete an activity when required.

## Dashboard

The dashboard displays:

* Total Steps
* Total Calories
* Total Workout Minutes
* Daily Progress Bars
* Weekly Activity Graph
* Recent Activities

## Objective

The main objective of this project is to create an easy-to-use fitness tracking application that helps users record and monitor their daily physical activities in one place.
